# Onix Barbershop — лендинг

Одностраничный сайт премиального барбершопа на русском языке.

- **`src/BarbershopLanding.jsx`** — весь лендинг в одном React-компоненте (React 18, Tailwind CSS, Framer Motion 11, GSAP 3 + ScrollTrigger, Lucide React).
- **`index.html`** — собранная страница, открывается в браузере без сборки (библиотеки грузятся с CDN).

## Что внутри

| Блок | Анимация |
| --- | --- |
| Интро-лоадер | Буквы «ONIX» на пружинах, счётчик 000→100, «разрез» золотой линией, экран расходится на две половины |
| Герой | Побуквенное появление заголовка, чертёж опасной бритвы из 4 полос: они въезжают навстречу друг другу и расходятся при скролле; параллакс фона и 3D-наклон за курсором |
| Бегущая строка | Скорость и наклон зависят от скорости скролла |
| Манифест | GSAP ScrollTrigger: слова поворачиваются в 3D по мере прокрутки, гильош-печать вращается |
| Наше ремесло | Карточки с 3D-наклоном, золотой рамкой за курсором, ценником-биркой на пружине и раскрытием «Что входит» |
| Ритуал визита | Закреплённая горизонтальная сцена (GSAP pin + containerAnimation), карточки разворачиваются в 3D |
| Мастера | Гильоширное «клеймо» мастера: при наведении увеличивается, поворачивается и из ч/б становится зелёным |
| Запись | Выбор услуги, мастера, дня и времени с «перетекающей» подсветкой, маска телефона, талон записи |
| Бейдж BOOK NOW | Вращается быстрее при скролле, притягивается к курсору, его можно перетаскивать |

`prefers-reduced-motion` учитывается: лоадер и скролл-сцены отключаются.

## Фото мастеров

Сейчас вместо фото у мастеров генеративные гильоши. Укажите `photo: "https://…"` в массиве `MASTERS`, и карточка покажет снимок с тем же эффектом (ч/б → цвет, приближение).

## Использование в своём проекте

```bash
npm i react react-dom framer-motion gsap lucide-react
```

Скопируйте `src/BarbershopLanding.jsx` в проект с Tailwind CSS и отрендерите `<BarbershopLanding />`. Шрифты (Sofia Sans Extra Condensed, Sofia Sans Semi Condensed, Golos Text) компонент подключает сам.

## Пересборка `index.html`

```bash
npm install
npm run build
```

Форма записи демонстрационная: заявка никуда не отправляется. Подключите `submit` в `Booking` к своей CRM или боту.
