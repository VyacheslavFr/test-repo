# Onix Barbershop — лендинг

Одностраничный сайт премиального барбершопа на русском языке.

- **`src/BarbershopLanding.jsx`** — весь лендинг в одном React-компоненте (React 18, Tailwind CSS, Framer Motion 11, GSAP 3 + ScrollTrigger, Three.js r128, Lucide React).
- **`index.html`** — собранная страница, открывается в браузере без сборки (библиотеки грузятся с CDN).

## Что внутри

| Блок | Анимация |
| --- | --- |
| Интро-лоадер | Буквы «ONIX» на пружинах, счётчик 000→100, «разрез» линией, экран расходится на две половины |
| Герой | Побуквенное появление заголовка и 3D-витрина на Three.js: филировочные ножницы (щёлкают лезвиями), массажная расчёска и фен по очереди появляются и вращаются. Модели — glTF из `models/`, без рамки и подписей; их можно крутить мышью или пальцем |
| Манифест | GSAP ScrollTrigger: слова поворачиваются в 3D по мере прокрутки. Рядом 3D-столб барбершопа (Three.js): стеклянная колба с бегущими спиральными полосами шалфей–крем–медь, латунные основание и капитель, молочный плафон-лампа. Полосы ускоряются при прокрутке, плафон разгорается при наведении; без WebGL — CSS-версия столба |
| Наше ремесло | Карточки с 3D-наклоном, мягкой подсветкой рамки за курсором, ценником-биркой на пружине и раскрытием «Что входит» |
| Наши работы | Лента фото гостей в один ряд: листается сама каждые 3 секунды, останавливается при наведении, свайпе или кнопкой паузы; её можно тянуть мышью и пальцем. Карточка в центре крупнее, остальные уменьшаются к краям. По клику — просмотр с листанием и записью на такую же стрижку |
| Ритуал визита | Закреплённая горизонтальная сцена (GSAP pin + containerAnimation), карточки разворачиваются в 3D. В каждой карточке на травертиновом подиуме медленно вращается 3D-предмет этапа (Three.js, один общий WebGL-рендерер на все карточки): ручное зеркало, флакон шампуня из янтарного стекла, беспроводная машинка (эргономичный корпус, рифлёная вставка, стальной нож на винтах с золотистым подвижным ножом, рычаг регулировки, ползунок питания и индикатор заряда), свёрнутое горячее полотенце с паром и баночка глины с медной крышкой. Предмет доворачивается при прокрутке и откликается на курсор. Внизу шкала визита: какие минуты из 60 занимает этап |
| Мастера | Карточка-арка мастера: при наведении увеличивается, цвет становится насыщеннее, появляется цитата |
| Запись | Выбор услуги, мастера, дня и времени с «перетекающей» подсветкой, маска телефона, талон записи |
| Бейдж BOOK NOW | Вращается быстрее при скролле, притягивается к курсору, его можно перетаскивать |

`prefers-reduced-motion` учитывается: лоадер и скролл-сцены отключаются.

## Фото

Фото гостей лежат в `clients/` (WebP, до 960 px по ширине; горизонтальные — до 1100 px по высоте) и описаны в массиве `WORKS`. Новые фото добавляются туда же.

### Фото мастеров

Сейчас вместо фото у мастеров пастельные арки с инициалами. Укажите `photo: "https://…"` в массиве `MASTERS`, и карточка покажет снимок с тем же эффектом (приближение, насыщенный цвет).

## Логотип

Исходник — `brand/onix-logo.webp`. Он векторизован potrace: `brand/onix-logo.svg` (полный логотип) и `brand/onix-mark.svg` (эмблема без надписи), а для компонента — `src/logo.js` с контурами, которые красятся через `currentColor`. Эмблема стоит в навигации и на заставке, полный логотип — в подвале, `brand/favicon.png` — иконка вкладки.

## 3D-модели

Ножницы, расчёска и фен на первом экране — модели с Sketchfab под лицензией [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), авторы указаны в подвале сайта:

| Файл | Модель | Автор |
| --- | --- | --- |
| `models/scissors.glb` | [Barber's scissors](https://sketchfab.com/3d-models/barbers-scissors-8b9086eed6a048f8967044fa92a65c4a) | [DUCK_](https://sketchfab.com/DUCK_THE_KILLER) |
| `models/brush.glb` | [Comb & Brush](https://sketchfab.com/3d-models/comb-brush-12e00d81ecd94ddbb9e3bdf34c3d2e19) | [Armin Rezaei](https://sketchfab.com/Armin2am) |
| `models/dryer.glb` | [Hair Dryer](https://sketchfab.com/3d-models/hair-dryer-4a32ed9cc04441bb83b480d056b6f314) | [sweedboy69](https://sketchfab.com/sweedboy69) |

Модели сжаты `gltfpack -cc -kn -km` (meshopt + квантование, 3,3 МБ → 0,47 МБ) и при сборке встраиваются в страницу как data: URL. У ножниц в исходнике нет материалов, поэтому сталь, силиконовые вставки и латунный винт задаются в коде; голубой пластик расчёски перекрашен в шалфей сайта. Если браузер не сможет распаковать модели, покажутся нарисованные в коде инструменты.

## Использование в своём проекте

```bash
npm i react react-dom framer-motion gsap three@0.128.0 lucide-react meshoptimizer
```

Скопируйте `src/BarbershopLanding.jsx` и папку `models/` в проект с Tailwind CSS (сборщик должен отдавать `.glb` как URL — в Vite это работает из коробки) и отрендерите `<BarbershopLanding />`. Шрифты (Lora, Manrope) компонент подключает сам.

## Пересборка `index.html`

```bash
npm install
npm run build
```

Форма записи демонстрационная: заявка никуда не отправляется. Подключите `submit` в `Booking` к своей CRM или боту.
